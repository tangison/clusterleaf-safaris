# Changelog

All notable changes to the Cluster Leaf Safaris website project will be documented in this file.

---

## [1.0.0] - 2025-01-12

### Added

#### Core Platform
- Initial Next.js 14 project setup with App Router
- TypeScript configuration with strict mode
- Tailwind CSS 4 configuration with custom brand colors
- Google Fonts integration (Playfair Display, Inter)

#### Pages
- **Home Page** - Hero section, trust signals, featured safaris, testimonials, CTA
- **About Page** - Company story, founder biography, philosophy
- **Safaris Listing** - Filterable safari grid by country and duration
- **Safari Detail** - Dynamic pages with itinerary accordion
- **Destinations** - Country profiles with highlights
- **Gallery** - Masonry layout with category filters and lightbox
- **Reviews** - Testimonials grid
- **Blog** - Index page with featured posts, detail pages
- **Contact** - Form with API route

#### Components
- Floating glassmorphic navigation with dropdowns
- Mobile off-canvas menu
- Safari cards with hover effects
- Testimonials carousel
- Trust signals section
- CTA sections
- Grain texture overlay

#### Features
- Typing animation for hero heading
- Ken Burns effect on hero background
- Sticky filter bar on gallery
- Lightbox with keyboard navigation
- Slideshow mode for gallery
- Favorites functionality (localStorage)
- Contact form with validation
- Toast notifications

#### Styling
- Neumorphic card styles
- Glassmorphic navigation
- Custom button styles (primary, sunset, glass)
- Responsive design for all breakpoints
- CSS custom properties for theming

#### Content
- 5 detailed safari itineraries
- 4 destination profiles
- 6 testimonials
- 5 blog posts
- Company and founder information

#### SEO
- Meta tags configuration
- Open Graph support
- Twitter cards
- Sitemap configuration
- Robots.txt

### Fixed
- Navigation three-zone layout for visual balance
- Dropdown menu hover behavior
- Mobile menu keyboard accessibility
- Image optimization warnings
